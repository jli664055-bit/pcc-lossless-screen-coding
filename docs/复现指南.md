# 复现指南

## 1. 环境

- 操作系统：macOS arm64（作者环境）或其他可编译 FLIF 的平台。
- Python 3.10 及以上，执行 `pip install -r requirements.txt` 安装 numpy、Pillow、imagecodecs 与 matplotlib。
- 编译编码器需要 clang++（或 g++）、make 与 zlib。

## 2. 数据准备

仓库直接提供：`data/synthetic_text/`（4000 张合成文字图像）、`data/dev_mix/`（6 张开发集混合主题图像）、`data/mixed_samples/`（4 张示例）。

需自行下载的公开数据集：SCID、SIQAD、Kodak、DIV2K。获取后执行：

```bash
python data/scripts/prepare_data.py --scid <SCID/ReferenceSCIs> --siqad <SIQAD/references> \
       --kodak <Kodak 目录> --div2k <DIV2K_valid_HR>
```

脚本生成灰度 PGM 图像、跨对比度与混合主题派生图像，并按 `data/checksums/` 校验。20 张真实浏览器截图不公开，其压缩结果只能由 `experiments/results/` 查阅。

## 3. 编码器

```bash
bash codec/build.sh          # 生成 codec/flif_pcc/src/flif
```

或直接使用预编译二进制 `bin/flif_v18_final`（macOS arm64）。

三个版本由环境变量切换，无需分别编译：

| 版本 | 环境变量 |
|---|---|
| v12 前序（串联组合） | `SMEM_LMIX=0` |
| v17 门控混合（无极性规范化） | `SMEM_LMIX=4 SMEM_PCC=0` |
| v18 本文方法 | `SMEM_LMIX=4 SMEM_PCC=2` |

完整参数见 `experiments/configs/v18_configs.json`（`base_env` 与 `configs`），v18_final 另需命令行参数 `-N -E60 -P0 -C -R0`。

单图验证：

```bash
python codec/pcc_codec.py encode data/mixed_samples/band_real01.pgm out.pcc --config v18
python codec/pcc_codec.py decode out.pcc restored.pgm
cmp <原图对应 PGM> restored.pgm
```

## 4. 逐图结果与汇总

```bash
python experiments/summarize.py               # 论文表 6.1
python experiments/summarize.py --polarity    # 图 1.1 的极性代价
```

输出与论文表 6.1 一致：SCID 19.08%、SIQAD 15.95%、真实截图 8.43%、跨对比度 17.92%、混合拼接 10.79%、混合分带 14.14%、DIV2K 0.37%、合成文字 25.77%。

重跑完整实验（需先准备数据）：

```bash
python experiments/scripts/v18/run_ours.py v18_final SCID,SIQAD,Real20,Kodak,Contrast32,MixHalf,MixBand,Synth,DIV2K100g --jobs 6
```

脚本可恢复，已完成的逐图记录会被跳过。

## 6. 结果文件字段

`experiments/results/v18/ours_*.json` 中每行对应一个（数据集，图像）：

| 字段 | 含义 |
|---|---|
| `bytes` | 编码后文件大小，含 8 字节文件头 |
| `lossless` | 完整解码后是否逐像素一致（全部为 true） |
| `enc_s`、`dec_s` | 编码、解码耗时（秒） |

`base_*.json` 为对照算法结果，字段 `source` 标明本次运行或沿用前序阶段同参数记录。
